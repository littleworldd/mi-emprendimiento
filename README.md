# Mi Emprendimiento

App Android para registrar ventas, gastos, deudas e inversión. Todo se guarda localmente en el teléfono.

**Descargar la app:** https://github.com/littleworldd/mi-emprendimiento/releases/latest/download/MiEmprendimiento.apk

El APK se compila solo con GitHub Actions cada vez que se sube un cambio.
